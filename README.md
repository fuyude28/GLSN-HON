# GLSN

This repository keeps the source code and the three input datasets. Generated figures, result tables, checkpoints, caches, and intermediate outputs are excluded. Experiment scripts write their outputs under their local `results` folders when run.

## Data

- `data/network-fo.csv`: first-order GLSN edge list.
- `data/network-ho.csv`: higher-order GLSN edge list.
- `data/port_system_mapping.csv`: physical-port system ID/name mapping.

## Install

Use Python 3.10+ and install the required packages:

```sh
python -m pip install -r requirements.txt
```

Run commands from this folder. For example, training-free baselines and the global bypass-link experiment:

```sh
python critical/baselines/run_baselines.py --method dynamic_total_degree
python critical/DND-DRL/train_dnd.py --episodes 18000 --out critical/DND-DRL/models/formal_best.pt
python critical/DND-DRL/evaluate_dnd.py --model critical/DND-DRL/models/formal_best.pt --out critical/DND-DRL/results/formal_removal_sequence.csv
python robustness/robustness_experiment.py
```

## Included Experiments

- `protect/`: renewed node-protection experiment and ranking integration.
- `robustness/`: history-consistent bypass-link addition, ranking-guided link experiments, and re-attack analysis.
- `rates/`: physical-port link-addition preflight and experiments. Port degrees are computed from `data/network-fo.csv`.
- `critical/`: DND-DRL/FINDER implementations and node-ranking baselines.
- `structural/`: network statistics and degree-model analysis.

## Inputs Generated At Runtime

The source datasets are included, but trained model weights and ranking sequences are not. Train or provide model checkpoints before neural-model evaluation. Node protection with learned/static ranking methods requires their corresponding checkpoint or ranking files. The main global bypass experiment requires a DND-DRL removal sequence; generate it with `evaluate_dnd.py`. Cross-ranking link comparisons require rankings from the selected baseline methods. Port-level experiments also require the DND-DRL removal sequence; generate it as above, then run `rates/preflight.py` before `rates/run_rates.py`. Node-protection ranking inputs can be generated with the included DND-DRL, FINDER, structural, and baseline ranking scripts; learned ranking options require a trained checkpoint. These inputs are generated by the included source code and are intentionally not bundled as results.

The plotting scripts and existing result/figure files are not included.
